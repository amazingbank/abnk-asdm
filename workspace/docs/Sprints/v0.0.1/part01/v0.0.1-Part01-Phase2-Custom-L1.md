## 背景与动机

Phase 1 实测把两块原判为 custom 的工作量清零（积数计息、对年对月对日均原生支持），Phase 2 的重心因此收敛为三件事：**定制骨架**（`custom/abnk/`，一切定制代码的唯一合法落点，ADR-002 红线：不改核心）、**L1 数据面**（COA/节假日/分录断言，多为数据工程）、**工程纪律**（CI 门禁 + rebase 流程）。

一处需要修正的 planning 层旧认知（本轮源码核验，2026-10-25）：根构建脚本对质量门禁的豁免条件是 `project.path.startsWith(':custom:acme:')`（checkstyle 见 `fineract/build.gradle` 595–615 行区间、SpotBugs 见 820–835 行区间）——**仅豁免 acme，不豁免 `custom/abnk`**；且所有 custom 模块（任意公司名）都会被加入 `fineractJavaProjects`（`fineract/build.gradle:379`），从而套上 checkstyle/spotbugs/jacoco/modernizer 全套官方门禁。含义：① `custom/abnk` 代码天然被官方质量工具覆盖（利好）；② 自建 CI 的重点从「补位被豁免的检查」转为「一键编排」（编译/单测/质量/冒烟/E2E 子集串行流水线 + 挂钩提交纪律）。

COA 是 Phase 2 关键路径且依赖会计专业输入（外部挂起门）：工程侧能先做且必须先做的是导入通道验证（任务 2.2），会计输入到位当天即可批量导入，关键路径不被工程阻塞。

## 任务分解

### 执行规则（全局）

1. **步骤强制执行**：逐步运行并记录实际输出；跳步 = 未完成；「编译通过」或「代码看着对」不算通过。
2. **顺序执行与任务门禁**：任务按编号顺序执行；**当前任务全部步骤通过并勾选后，下一任务方可开始**；任一步骤失败即停，修复后从该步骤重跑。
3. **步步有验收**：每个步骤紧跟可执行验证动作（命令 + 期望输出）；无验收动作的步骤不得勾选；实测-vs-期望是唯一通过判据；探查类步骤的验收 = 实测记录归档 + 表格填写（无空格）。
4. **占位符声明**（本文统一）：`$FINERACT` = `https://localhost:8443/fineract-provider`；`$TENANT` = `Fineract-Platform-TenantId: default`；`$AUTH` = `Authorization: Basic bWlmb3M6cGFzc3dvcmQ=`；`$PSQL` = `docker exec abnk-pg psql -U root -d fineract_default`；`$PSQL_T` = `docker exec abnk-pg psql -U root -d fineract_tenants`；`$JDK25` = `~/.sdkman/candidates/java/25.0.5+8-tem`；`$FINERACT_REPO` = `/Users/leixu/source/asdm/amazingbank-ws/fineract`；`$ABNK_REPO` = `/Users/leixu/source/asdm/amazingbank-ws/abnk-system`；`$WS` = `/Users/leixu/source/asdm/amazingbank-ws`（端口/路径出处：toolset `config.json` / `application.properties` / `docker-compose.yml`；**应用日志实测位于 `$WS/logs/fineract.log`**——toolset `config.json` 的 `logFile` 为相对路径，实测解析到工作区根，非 `fineract/logs/`）。
5. **状态标注**：执行前 ⏳ 待执行，全部步骤通过后改 ✅ 已完成（本表与 Plan.md 同步）。
6. **编译重启铁律**：任何 Java 改动后 `./gradlew :custom:abnk:<...>:classes`（仓库 wrapper，禁系统 gradle）→ `lsof -ti:8443 -sTCP:LISTEN | xargs kill` → `nohup ./gradlew devRun` → 等 `APACHE FINERACT IS READY`（READY 日志时间戳须晚于源文件 mtime）→ 再验证；涉及 schema 变更（custom-changelog）时验收含 `databasechangelog` 新行核对。
