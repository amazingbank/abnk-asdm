## 决策记录（2026-11-06 用户拍板）

| # | 决策 | 内容 |

| D5 | 运行形态 | 容器化（prod 形态）；本地开发可先宿主进程 |

| 附 1 | Apple 开发者账号 | 用户后续提供（任务 P3.6 ipa 签名的条件门） |

## 部署目标与架构口径

- 服务端与网页端部署到 **amazingbank.ai 所在服务器**（`abnk-vm001`，部署铁律见 `abnk-prod-deploy.md`：服务端构建、`--env-file`、敏感信息只进 `.github-private`、两阶段发布 + 用户确认铁门）。
- 域名规划（复用既有 `*.amazingbank.ai` 通配符证书，零新增证书成本）：`api.amazingbank.ai`（网关）、`app.amazingbank.ai`（手机银行 web）、`bo.amazingbank.ai`（Backoffice）。
- 生产形态 Fineract = **WAR + Tomcat（HTTP 8080，容器内网）**——公网 TLS 终止在网关层；Fineract 8443/8081 永不对公网。**（2026-11-07 D7 调整：P0.4 服务器平台栈 8080 直接公网暴露——「永不对公网」对平台栈放开，NSG 放行 8080 为前置；网关收口仍按 P3 计划。）**
- 平台生产形态的构建范式（实测依据：`fineract/docker-compose-war-test.yml`）：`./gradlew :fineract-war:war` → `fineract-war/build/libs/fineract-provider.war` → `tomcat:10.1.59-jdk25-temurin` 挂载部署，`FINERACT_SERVER_SSL_ENABLED=false`，DB 连接经 `FINERACT_HIKARI_*` / `FINERACT_DEFAULT_TENANTDB_*` env 注入。
