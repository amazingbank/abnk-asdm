### 已知环境坑

1. **Vite 大数据集构建性能**：`src/data/` 含 100+ md 全文与全部证据文件索引（2026-11-16 审核实测 part01–03 合计 380，迁移基线 336——分桶随各 Part 证据增长，勿硬编码总数）——md 走 `import.meta.glob`（懒加载按路由拆 chunk）；**截图等二进制资产不 import 进 JS**——构建期复制到 `public/evidence/` 由 nginx 直供 + 静态资产清单 JSON（D4「构建纯复制」在资产层的体现）。
2. **内链路由转换是最隐蔽的坑**：md 里相对链接（`./Phase2-...md`、`../../../Sprints/...`）是文件系统语义，页面里是路由语义——转换层**集中一处**（`src/lib/link-resolver.ts`，六页面共用）；散落各页面的字符串替换会在内容更新时静默断链。指向 sync 范围外的形态降级为源仓 GitHub 链接并显式标注。
3. **三态视觉层次不重新发明状态**：文档状态以 front-matter 为准（V5.4.3 已保证与正文一致）；步骤勾选态（`- [ ]`/`- [x]`）与执行输出块由渲染管线加样式钩子——渲染不判定状态只呈现状态。
4. **指标诚实性是判据不是口号**（D6）：仪表盘必须有「状态如实」组件——挂账项渲染挂账样式、CI 徽标显示「未实跑 · 规划中」；V3.4.3 有机械判据。
5. **图片资产 locale 无关**：证据截图 en 渲染复用同一物理文件（Part03 D4 修订口径）——资产复制不做 locale 分叉。
6. **npm 而非 pnpm/yarn**（全仓惯例）；路由库选型跟随 website/backoffice 实际形态（执行时核验）。
7. **index 的 TS 消费形态是执行时决策点**：`src/data/` 内 sprint index 是 **yaml** 原样复制（Phase 1 口径）——页面消费走哪条路执行时定死并记入报告：①生成器侧补产 `sprint-v0.0.1.json`（推荐——D4「提取入库」口径的自然延伸，portal 保持纯复制；生成器增量走契约双侧同步，V1.2.3 互证口径）或 ②`import.meta.glob '?raw'` + 运行时 yaml 解析（引入 js-yaml 依赖，构建仍零提取）。**勿**在页面组件内散落解析（V3.2.1 纯度判据把守）。

## 背景与动机

数据管线与内容就绪后 portal 仍是空壳——社区用户看到的一切在本 Phase 诞生。六任务按「骨架 → 数据页面 → 渲染器」排序：路由先立（挂载点存在），四个数据页面消费契约渲染真实资产，证据浏览页最后接 markdown 渲染器收口（它最复杂：渲染 + 路由转换 + 三态层次，页面模式稳定后一次做对）。

## 方案要点

1. **契约唯一**：六页面全部从 `schema.ts` 类型出发——数据不够用改契约（生成器/契约双侧同步，V1.2.3 互证口径延续），页面内零原始解析（V3.2.1 机械判据）。
2. **灵魂页面 = 迭代时间线四层下钻**：Sprint → Part → Phase → Task，每层链到证据指针——「证据链可被点击验证」是 portal 核心叙事（V3.2.2 覆盖含移交往返的全路径走查）。
3. **诚实性三处硬判据**：指标页挂账/移交/CI 如实（V3.4.3）、证据浏览三态不美化（V3.6.2）、E2E 旅程问题记录原样（V3.5.2）。
4. **渲染器与路由转换集中**：`src/lib/` 单点（已知坑 2/3），页面只组合。

## 任务分解

**执行规则（全任务生效）**：

1. 步骤必须实际执行并记录真实输出；跳步、肉眼过页面，均不算通过。
2. **任务门禁**：任务按 ID 顺序执行；当前任务全部步骤通过并勾选后，下一任务方可开始；任一步骤失败即停，修复后从该步骤重跑。
3. **步步有验收**：每个步骤紧跟可执行的验证动作（编译命令/界面走查/数据断言）+ 期望输出；界面走查 = dev server 浏览器实测 + 截图归档 `$ART/screenshots/`（`{页面}-{语言态}-` 前缀命名）。
4. 占位符 `$PORTAL`/`$ASDM`/`$ART` 按「前置条件·占位符声明」解析。
5. 状态标注：任务执行前为「⏳ 待执行」，全部步骤通过后改「✅ 已完成」。
6. **编译门槛铁律**：每任务收口三绿 + `npm run build` 产物存在 + `npm run preview` 冒烟可达。
7. **双语注释铁律**：触碰的每个源码文件注释一律中文在上、英文语义重写在下。
