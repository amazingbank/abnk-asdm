## 总体口径（铁律，全 Part 生效）

- **单一事实源**：portal 不生产内容、无 portal 专用文档——文档双用途（工作载体 + 展示内容），展示素材全部来自 abnk-asdm 仓既有资产；唯一新创作板块是方法论改写（源自 asdm-training 体系，Phase 2）。
- **front-matter 正向书写**：本 Part 全部新文档从第一天直接带 front-matter（不做事后注入）——依赖 Part03 Phase 5.4 已定型 schema；状态勾选 = 同时改 front-matter status 字段与正文 emoji。
- **三合一门管辖**：本 Part 开发期新增的代码与文档全程受 Part03 Phase 6 的 check-bilingual 三合一门（注释双语 + front-matter + 凭据扫描）管辖；CI 接入前以工具集走查代跑。
- **en-US 工作量克制**：只语义重写核心页（首页/方法论概览/时间线骨架），深链内容 zh 优先 + fallback 声明——防 Phase 2 膨胀成翻译工程（D2 哲学：en 是语义重写不是翻译）。
- **验收运行器**：portal 侧 `npm run typecheck` / `npm run lint` / `npm run build`（npm，非 pnpm/yarn，对齐 backoffice/website 惯例）；界面走查 = dev server 浏览器实测 + 输出记录归档；构建产物验收 = ghcr 镜像 + 部署后域名实测。
- **走查记录归档**：`abnk-asdm/workspace/docs/Sprints/v0.0.1/part04/artifacts/phase<N>/`（D9 归仓后新位置，本 Part 即新结构的第一批实践者）。
- **不碰业务系统**：本 Part 零 abnk-system 代码改动（唯一例外是 Phase 4 官网 CTA——abnk-website 仓的 Asdm/OpenSource 板块加链接，跨仓最小改动）；gateway/fineract 不触碰。
