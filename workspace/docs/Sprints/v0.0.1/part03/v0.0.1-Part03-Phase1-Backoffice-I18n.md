## 背景与动机

backoffice 当前零 i18n 机制：`src/main.tsx:4` 写死 `antd/locale/zh_CN`、`main.tsx:18` ConfigProvider locale 固定；pages（4 个）+ components（7 个）约 105 行硬编码中文文案（非注释口径，2026-11-12 审核实测，与 V1.6.2 判据同口径；含注释行为 115）；`src/utils/format.ts:4` 写死 `zh-CN` 数字格式；`index.html:2` `lang="zh-CN"`、`:7` 中文标题。Amazing Bank 是面向全球开发者的开源项目，需要双语 UI 与中英切换。abnk-website 已验证零依赖自建 i18n 方案（含编译期词条结构校验），backoffice 与之同构复刻，保证仓内两个 React 载体一套心智模型。

## 方案要点

1. **零依赖自建**（D5）：不引入 i18next；`src/i18n/` 7 模块与 website 同名同构（`locale-url.ts` 除外，D6 无 URL 前缀），词条为 JSON 静态 import 打进主包（词条量级数百条，无需懒加载）。
2. **类型安全**：中文包是类型事实源（`Widen<typeof zhXxx>`），英文包 `satisfies Translations` 编译期校验——缺 key/结构漂移在 `npm run typecheck` 拦截。
3. **命名空间**：`common`（布局/菜单/通用）/ `login` / `clients` / `loanOps` / `errors`（errors 本 Phase 先建骨架，词条随任务 1.6 落部分、Phase 2 任务 2.1 补全）。
4. **localStorage 事实源**（D6）：初始 locale = `localStorage['abnk-locale']` ?? `resolveBrowserLocale()`；切换写入存储 + 就地 setState 重渲染（无页面刷新）；与 website 的 URL 前缀方案差异在 `locale-provider.tsx` 注释中声明理由。
5. **antd/dayjs 联动**：`main.tsx` 的 ConfigProvider 抽为 `AppProviders`，随 locale 动态映射 `zh_CN`/`en_US`；dayjs `locale('zh-cn'/'en')` 同步。
6. **英文词条语义重写**（D2 铁律）：en-us 词条按英语母语者与金融行业惯用语组织，不逐字直译。
7. **`{param}` 插值**：复用 website `interpolate.ts` 同构实现（`共 {total} 名客户` / `Total {total} clients`）。
