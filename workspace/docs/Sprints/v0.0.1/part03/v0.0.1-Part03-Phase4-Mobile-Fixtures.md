### 已知环境坑

1. **Flutter 资产不做编译期剔除**：与 backoffice（Vite tree-shaking 单集进 bundle）不同，`fixtures/{zh-cn,en-us}` 两套资产都会打进产物——选择正确性不能靠「产物缺席」判据，也不能靠「不含对侧字符串」判据（`fixtureDirFor` 函数体内两态目录字面量均会编入 `main.dart.js`，优化器是否内联消除不可依赖）；确定性证明 = define 传播测试两向（`V4.2.5` ③）+ 运行行为（`V4.2.6/7`），`main.dart.js` grep 仅作弱断言。两载体判据体系差异是设计差异，不是缺陷。
2. **`String.fromEnvironment` 是编译期常量**：改 `--dart-define` 必须完整重建；`flutter test` 默认无该 define → `defaultValue: 'zh-cn'` 生效——测试 zh 态口径天然稳定（与 Phase 3 测试 zh 断言一致）。
3. **pubspec assets 目录声明不递归子目录**：文件级五条声明必须换成目录级两条（`fixtures/zh-cn/` + `fixtures/en-us/`）；漏声明运行时 `rootBundle` 报 `Unable to load asset`（不是编译错——静态检查抓不住；**test 链路对此把关失效**：测试经 `seedForTests` 磁盘直读、完全绕开 rootBundle——`test_app.dart` 头注释口径，漏声明时 `V4.2.1` 测试依然全绿；真正把关 = `V4.2.5` ① build 资产目录核对（`ls build/web/assets/assets/fixtures/` 双目录在场即声明生效）+ `V4.2.6/7` 运行时走查）。
4. **测试种子磁盘直读**：`test/helpers/test_app.dart:30` 从 `fixtures/$name` 读盘——4.1 移动文件后该路径必失效，4.2 同步改 `fixtures/zh-cn/$name`（漏改 = 测试全红，属预期中间态，见前置条件门槛第一层）。
5. **git mv 保历史**：五个 JSON 的移动与 pubspec 声明变更同任务落地，不同任务混提交会造成 assets 声明与文件位置漂移。
6. **web 首启编译等待**：`flutter run -d web-server` 首启编译约 30s+，判据 = 载体日志出现 `is being served at`/run key commands 输出后再执行走查动作（同 Phase 3 坑 8 口径，实测形态）；语义树断言依赖 `--dart-define=ABNK_ENABLE_SEMANTICS=true`（`main.dart` 仅经该 define 开启 semantics，不加则自动化快照无文本）。
7. **en 数据集以 zh 为结构源**：字段/记录数/嵌套键集合与 zh 完全一致，仅文案语义重写——结构漂移靠 `V4.1.2` 脚本比对（Dart 侧无 `satisfies` 等价物，靠判据步骤把关）。

## 背景与动机

Phase 3 完成后 UI 文案已 arb 化，但 mock 数据仍单语中文：fixtures 根目录 5 个 JSON 的产品名/交易备注/贷款产品名与描述/证照类型名是直上屏数据（`home_page`/`transactions_page`/`loans_page`/`profile_page` 直接渲染），英文 UI 下数据仍是中文；mock 层 3 行 note 兜底串（`V3.4.2` 精确放行项）同属数据文案。D3 要求双语两套数据集 + 部署期切换——backoffice 侧已由 Phase 2 任务 2.2 落地同一变量 `ABNK_DATA_LOCALE`，本 Phase 完成 mobile 侧对齐。

## 方案要点

1. **编译期数据集选择（D3）**：`String.fromEnvironment('ABNK_DATA_LOCALE', defaultValue: 'zh-cn')` 编译期常量决定 fixture 目录（`fixtures/zh-cn/` / `fixtures/en-us/`）；部署链 = env `ABNK_DATA_LOCALE` → Dockerfile `ARG` → `flutter build web --dart-define`（对齐 `ABNK_API_BASE` 先例）。运行时 UI 语言切换不切数据集。
2. **`load(name)` 签名不变**：`FixtureBundle.load` 仅内部改路径（`fixtures/$dataLocale/$name`），缓存 key 维持文件名——9 处消费点（mock repos 8 + test helpers）调用面零改动；数据集选择收口单一事实源。
3. **纯函数化选择器**：目录决策提为 `@visibleForTesting` 纯函数 `fixtureDirFor(String locale)`，可测不依赖编译常量。
4. **note 兜底串迁双语常量**：`mock_account_repository.dart:186/:192/:231` 三行迁入 mock 层数据集常量（`lib/data/mock/data_locale.dart`：`dataLocale` 常量 + note 兜底双语映射函数），Phase 3 残留清零。
5. **en 数据语义重写（D2）**：中文数据字段按英语银行业惯用形态重写（`ABNK 活期储蓄` → `ABNK Current Savings`、`身份证` → `National ID`、`初始存入` → `Initial deposit` 等）；`me.json` 既有英文内容保持；结构字段与 zh 完全一致。
6. **测试 zh 态稳定**：`defaultValue: 'zh-cn'` + test helpers 直读 `fixtures/zh-cn/`——现有测试断言零适配成本。
7. **边界**：remote 模式数据不翻（D3）；原生层不动；三载体 drive 走查归 Phase 6 任务 6.3；服务端 Docker 镜像构建验证出界（同 Phase 2）。
