## 决策记录（2026-11-11 用户拍板）

| # | 决策 | 内容 |
|---|---|---|
| D1 | 初始语言 | **跟随系统**：任一系统语言 tag 以 zh 开头 → zh-cn，否则 en-us（与 abnk-website `resolveBrowserLocale` 同口径）；用户手动切换后以持久化偏好优先 |
| D2 | 词条语言方向 | **中文为源（template），英文为语义重写**——按英语母语者与金融行业惯用语组织句子，不逐字直译（如「等额本息」→ amortizing loan with equal monthly installments）；适用于 en-us JSON 词条与 `app_en.arb` |
| D3 | 数据文案 | **双语两套数据集 + 部署期切换**：mock/fixtures 提供 zh-cn/en-us 两套完整文件，由统一环境变量 `ABNK_DATA_LOCALE`（来源部署 env 样例 `abnk-system/deploy/prod/env/abnk-fullstack.env.example`，经 Dockerfile `ARG` 注入——链路 Phase 2 任务 2.2 落地）选择——backoffice 经 Vite 构建注入、mobile 经 `--dart-define` 注入；运行时 UI 语言切换**不**切换数据集；真实后端多语言数据不在本轮范围（另立 Phase） |
| D4 | `.asdm` 双语范围 | **仅 `workspace/`**：现有内容整体迁入 `workspace/zh-CN/`，建 `workspace/en-US/` 骨架（内容按需后补，不要求一次性翻译）；toolsets 内容**不动**，但其引用的 `.asdm/workspace/...` 路径随迁移同步 |
| D5 | backoffice 选型 | **零依赖自建 i18n，与 abnk-website 同构**（`resources/locale-context/locale-provider/use-locale/interpolate` 同名同构，JSON 词条 + `Widen` 类型推导 + `satisfies` 编译期结构校验）；不引入 i18next 等第三方库 |
| D6 | backoffice 语言事实来源 | **localStorage（方案 A）**：URL 无语言前缀、路由层零侵入；与 abnk-website 的「URL 前缀唯一事实源」差异是有意的（工具型应用无 SEO/分享诉求，website 方案自述其前缀选择是单页锚点站场景驱动），差异在 i18n 模块注释中声明 |
| D7 | mobile 选型 | Flutter 官方 `gen-l10n`（ARB），template 为 `app_zh.arb`；语言切换走既有 `AppState`（ChangeNotifier）+ `ListenableBuilder` 整树重建链路，不新增状态管理依赖；持久化引入 `shared_preferences` |
| D8 | locale 命名 | 代码层统一小写 `zh-cn` / `en-us`（与 abnk-website 一致，BCP 47 大写仅用于 `<html lang>`）；`.asdm` 目录按 D4 用大写 `zh-CN` / `en-US` |
| 附 | Part 挂载 | `v0.0.1/part03`（用户默认确认）；Phase 2–6 文档随执行细化 |

## 总体口径（铁律，全 Part 生效）

- **英文词条一律语义重写**（D2）——每个词条任务的验收都携带此口径。
- **数据集选择是部署期决策**（D3）——运行时切换语言不切数据集；UI 词条与数据集互不耦合。
- **注释双语规范**：本次 i18n 触碰的文件注释一律双语（中文在上、英文语义重写在下）；存量未触碰文件不追溯，Phase 6 以 check-bilingual 脚本防回潮。
- **验收运行器**（不得写错）：
  - backoffice：`npm run typecheck`（`tsc --noEmit`，`satisfies` 缺 key 在此拦截）/ `npm run lint` / `npm run build`（npm，非 pnpm/yarn）；界面走查 = dev server（:6203，strictPort）浏览器实测 + 输出记录归档。
  - mobile-banking：`flutter gen-l10n` / `flutter analyze` / 三载体 `flutter drive` 截屏归档（对齐 Part02 P1.3 走查惯例）。
- **走查记录归档**：`abnk-system/artifacts/part03/phase<N>/`（沿用 Part02 artifacts 归档惯例，按 part03/phase 前缀区分）。
- **gateway 口径**：无用户可见 UI，无运行时 i18n 交付物；其代码如在本 Part 中被触碰，遵守注释双语规范。
