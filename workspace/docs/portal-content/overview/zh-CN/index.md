# Amazing Bank Dev Portal——首页导览

> 你现在看到的，是一个银行核心系统项目把软件工程过程**完整摊开**的窗口：规划、决策、迭代、证据、指标，全部原样披露。本站不生产内容——所有展示素材来自工程工作区的结构化资产，按原样渲染。

## 这是什么项目

Amazing Bank 是一个用 ASDM 方法论（AI-Driven Software Development）交付的银行核心系统项目：以 Apache Fineract 为核心引擎，配套移动端、后台管理与开放门户。它同时是 ASDM 官方的 L3 级复杂度实践案例——银行核心系统、多系统集成、安全合规要求。

这个 Dev Portal 回答一个问题：**当一个组织声称「用 AI 驱动开发」时，过程资产长什么样？**

## 八大板块

| 板块 | 看什么 |

| [方法论](../methodology/zh-CN/index.md) | ASDM 三大工程（上下文/驾驭/循环）——读懂迭代记录的坐标系 |

## 两条阅读原则

1. **透明包括透明地展示未完成**：迭代中的挂账项、移交任务、尚未实跑的 CI，都在指标仪表盘按「规划中/挂账」如实标注——不掩盖、不虚构。这是本项目的诚实性铁律；
2. **证据优先于叙事**：每个结论都能下钻到原始证据（命令输出、截图、测试报告）。如果你对任何说法有疑问，去看它的证据链。

## 数据从哪来

本站是**构建时静态渲染**：工程仓（abnk-asdm）的过程资产由生成器聚合成索引与指标、随 git 入库（git history 即数据可信度审计记录），portal 构建时只读复制、零提取逻辑——任何人 clone 两个仓库即可完整复现本站，详见复现指南。

从[迭代时间线骨架](./timeline.md)开始你的下钻，或先读[方法论总览](../methodology/zh-CN/index.md)建立坐标系。
