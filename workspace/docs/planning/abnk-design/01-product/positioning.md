# 产品定位与价值主张

> **性质**：设计文档（非实测事实）。事实依据来自 `00-baseline/` 与 ADR-001/006。

---

## 1. 一句话定位

**基于 Apache Fineract 构建的中国本土数字银行 IT 系统**——复用全球验证过的核心账务引擎，把工程力量全部投在产生差异的地方。

## 2. 价值四支柱

| 支柱 | 内容 | 落点 |
|---|---|---|
| **本地化** | 中国监管合规、会计准则、业务习惯（计息/证照/币种/时区） | L1（`05-domains/`） |
| **渠道体验** | 柜面 / 网银 / 手机银行 / 管理后台，体验完全可控 | L3（ADR-005） |
| **外围集成** | 支付（网联/银联）、征信、反洗钱、监管报送——事件驱动解耦 | L4（`event-bus`） |
| **数据智能** | 代码本体（AOS）+ 数仓 + AI 应用，长期差异化 | L5（`aos-integration`） |

## 3. 明确不做的事

- **不自研核心账务**：复式记账、计提、日终、逾期分类——Fineract 十余年积累（ADR-001）
- **不深改贷款引擎**：progressive-loan 的 schedule 生成器等复杂内核以配置和扩展点使用，不重写
- **不做万能银行的第一天**：产品线三波次收敛（ADR-006）

## 4. 差异化逻辑

开源核心 + 自建外围的组合意味着：**核心成本趋近于零（跟随上游演进），工程预算 100% 投向竞品 hardest 的部分**（本地合规深度 + 渠道体验 + 数据智能）。传统银行核心采购在这三处恰恰最弱。

## 5. 成功度量（对齐 roadmap 出口判据）

- **工程**：本地 5 分钟起整套环境；fork 季度级 rebase 无冲突
- **质量**：官方 E2E + 12 步冒烟全绿；定制模块 CI 门禁通过
- **业务**：第一波产品线（储蓄+消费贷）全链路端到端可用
- **交付**：定制改动从提交到上线 < 1 天
